# Gate Controller v1 — Итоговая спецификация (rev E)

**Статус:** **READY FOR SCHEMATIC ENTRY** — архитектура зафиксирована. Допускается переход к разработке принципиальной схемы и предварительному размещению компонентов. Трассировка POWER PCB начинается только после выбора финального part number силовых реле (§10).

**Дата:** 2026-10-29 · **Журнал ревизий:** §18. Предыдущие редакции (rev A–D) переработаны по двум раундам ревью; настоящий документ самодостаточен — схема строится по нему, а не по старым редакциям.

---

## 1. Назначение

Контроллер автоматических ворот с:

- фазовым управлением AC-двигателем 230 В (phase angle control);
- измерением положения по энкодеру;
- аппаратными концевыми выключателями (независимый канал безопасности);
- защитой anti-pinch по току двигателя (CT + усилитель);
- Wi-Fi подключением (внешняя антенна);
- RTC и журналированием событий (DS3231M + EEPROM);
- резервным питанием логики от АКБ 12 В;
- возможностью подключения отдельного модуля камеры (§5).

## 2. Архитектура изделия

### 2.1 Структура — две платы на одной панели

Изделие состоит из двух плат, изготавливаемых **на одной производственной панели 100×100 мм** и разделяемых после сборки (V-groove/перфорация между ними).

**POWER PCB** — силовая плата:
- вход сети 230 В;
- сетевая защита (MOV, предохранитель);
- фильтр EMC (X2, CM-дроссель, Y1);
- AC/DC источник питания (HLK-10M12);
- фазовый регулятор двигателя (MOC3023 + BTA16);
- реле направления K1/K2 и шунтирующее K3;
- детектор перехода через ноль (H11AA1).

**LOGIC PCB** — логическая плата:
- ESP32-S3-WROOM-1U-N16R8;
- buck 3.3 В (TPS563201);
- измерительный тракт тока (CT → AD8237 → ADC);
- RTC DS3231M, EEPROM 24LC256;
- интерфейсы пользователя (кнопки, зуммер, LED);
- USB-C;
- датчики (концевики, энкодер, probe, NTC);
- UPS логики (LTC4412 + AO3401, вход J_BATT).

Межплатные соединения — через барьерные компоненты (оптроны, реле, HLK) и силовые жгуты MOTOR / AC-IN; цифровые сигналы MAINSIDE↔LOGIC идут только через оптроны H11AA1/MOC3023 и катушечные цепи реле (см. §8).

### 2.2 Закрытые open decisions (итог rev C–E)

| # | Вопрос | Принятое решение |
|---|--------|------------------|
| D1 | Аварийное закрытие при пропадании сети | **Не предусматривается.** AC-двигатель питается от сети; UPS держит только логику. Штатное аварийное управление — механическая разблокировка |
| D2 | Одна плата с пропилом или две | **Две платы на общей панели 100×100 мм** |
| D3 | Антенна | **ESP32-S3-WROOM-1U (u.FL) + выносная внешняя Wi-Fi антенна** |
| D4 | Камера | **Исключена из базовой платы**, отдельный дочерний модуль (§5) |
| D5 | Заряд АКБ | **Внешним буферным ЗУ**; on-board CC/CV нет, плата только разряжает (ideal diode) |
| D6 | Форм-фактор | Панель 100×100 мм, полезный контур 98.5×98.5 мм (§6–7) |

## 7. Геометрия плат

### POWER PCB — ориентировочно 98 × 58 мм

Состав (top-to-bottom по потоку мощности):

```
AC-IN → MOV 14D471K → F1 T5A → X2 0.47µF → CM choke 10 mH → Y1 2.2nF
      → HLK-10M12 (барьер) → шина 12 В → K1/K2/K3 (катушки через барьер)
      → MOC3023 (барьер) → gate BTA16 → BTA16-800BW (радиатор/шасси) → MOTOR
      → H11AA1 (барьер) ← 2×68 кОм делитель от L
```

### LOGIC PCB — ориентировочно 98 × 34 мм

Состав:

```
ESP32-S3-WROOM-1U (u.FL на край) · TPS563201 · LTC4412+AO3401 (J_BATT, fuse 3A)
RTC DS3231M (CR2032 holder) · EEPROM 24LC256 · USB-C · AD8237+REF3033+OPA314
полевые разъёмы: ENC / LIMIT / PROBE / CT · кнопки · зуммер · LED
```

Разделение POWER/LOGIC на панели — линия разлома между ними; барьерная зона (§8) проходит по линии разлома и дополнительно внутри POWER PCB (первичка HLK ↔ вторичка).

## 8. Изоляция

Сохраняются три зоны.

### MAINS (230 VAC)
Силовая часть: AC-IN, MOV, X2, CM choke, первичка HLK-10M12, силовые контакты K1–K3, BTA16, MOTOR, входной делитель H11AA1.

### BARRIER
Барьерные компоненты: **HLK-10M12, MOC3023, H11AA1, силовые реле**.

Минимумы:
```
Clearance ≥ 4 мм
Creepage  ≥ 6.4 мм
```
Под барьером запрещены: дорожки, полигоны, переходные отверстия, компоненты — **с обеих сторон платы**. На 2-слойной плате creepage обеспечивается шлицем ≥ 4 мм до края/между площадок; для reinforced-требований реле выбираются реле с собственной изоляцией катушка↔контакты ≥ 4 кВ (§10), т.е. барьер «переезжает» внутрь компонента, а на плате держим минимум 4 мм clearance.

### LOGIC (SELV)
Максимум: **< 30 В DC** (шина 12 В, 3.3 В, 5 В camera-link — всё SELV).

## 9. Силовая часть

### TRIAC
```
BTA16-800BW · 16 А · 800 В · Snubberless
Установка: на шасси корпуса через изолирующую прокладку (thermal pad + слюда/керамика, крепёж M4, изолирующие втулки)
Потери: ~1.2 В × 3 А ≈ 3.6 Вт непрерывно — радиатор обязателен (Rθ ≤ 8 К/Вт даёт ΔT ≈ 29 К)
```

### Драйвер
```
MOC3023 (random-phase, без zero-cross детектора внутри)
Управление: GPIO10 → R_LED 220 Ом → I_F ≈ 9.5 мА (IFT max 5 мА, запас ×1.9 на −30 °C и деградацию LED)
Gate-цепь: R_GK 36…100 Ом, DB3(DIAC) не используется
Pull-down 100 кОм от узла GPIO10 к GND — гарантия off-состояния при reset MCU
```

### Zero Cross
```
H11AA1, вход: 2 × 68 кОм/0.5 Вт (рабочее напряжение ≥350 В каждое) → I_LED ≈ 1.7 мА
Выход: open-collector, pull-up 10 кОм к 3.3 В → GPIO14 (NEGEXTD ISR)
Фронт на каждый полупериод (10 мс); loss-of-mains budget: 2×20 мс + debounce 15 мс = 55 мс (§17 тест ≤ 60 мс)
```

## 10. Реле

Три силовых реле на POWER PCB:

| Позиция | Функция |
|---------|---------|
| K1 | OPEN (фаза на обмотку «открытие») |
| K2 | CLOSE (фаза на обмотку «закрытие») |
| K3 | SHUNT (шунтирование triac после полного хода — экономия ~3.6 Вт и ресурса triac) |

**Обязательные требования:**
```
Контакты: ≥ 16 А, AgSnO2 (inductive rated), 250 VAC
Изоляция катушка↔контакты: ≥ 4 кВ RMS (reinforced per IEC 62368-1 / documented in datasheet)
Сертификация: VDE/UL/CQC — обязательна строка в datasheet, не «похоже на reinforced»
```

**Кандидаты (footprint-класс 16 A power relay, 29×12.7 мм, шаг 5 мм):**

| Серия | Примечание |
|-------|-----------|
| TE RT1 / RTP | 16 А, reinforced-варианты есть в линейке — проверять конкретный код заказа |
| Omron **G2RL-1A-E-GFS** | 16 А, coil↔contacts 5 кВ/0.5 мин (reinforced doc'd), пайка без свинца |
| Panasonic ALZ/LZ | 16 А класс, проверять RL-серии с reinforced |
| Hongfa HF115F-F | 16 А, бюджетный; сертификацию сверить до заказа |

Отменены ранее рассматривавшиеся: G5NB (SPST-NO, basic isolation), G6K-2F (сигнальный класс 1 А), Songle SRD (нет подтверждённой reinforced-строки), золотое покрытие контактов (недопустимо на силе).

**Mutual lock (режим fail-off):** драйверы K1/K2 — два 2И **74LVC2G08** с инвертированным входом (`Q1_en = G11·¬G12`, `Q2_en = G12·¬G11`), выходы через pull-down 100 кОм. При reset/плавающих GPIO гарантированно 0 В на затворах обоих MOSFET. Тест — §17. Программный dead-time 60 мс остаётся первым рубежом.

**Финальный part number обязателен до трассировки POWER PCB** (размеры окон и зазор барьера зависят от корпуса выбранного реле).

## 12. UPS логики

```
Контроллер ideal diode: LTC4412 (контроллер, требует внешний P-MOS)
P-MOSFET: AO3401 (−20 В / −4 А) — source к +BAT, gate к PGATE LTC4412
Резервный schottky: SS56 (на случай отказа PFET-канала)
OR-ing: канал PSU (HLK 12 В) и канал АКБ сливаются на шину 12 В логики
Защита батареи: F2 = 3 A fast + AO3401 reverse protection (переполюсовка)
Политики fw: low-batt stop at 10.5 В (BATT_DIVIDER=5.7, см. §13.2)
Заряд: внешним буферным ЗУ (D5-a); NTC на плате — телеметрия + thermal inhibit
```

## 13. Тракт измерения тока и аналоги

### 13.1 CT
```
Трансформатор: SCT-024-009 (24 А : 9 мА) split-core — ⚠ коэффициент проверить перед закупкой (партномер у поставщика может отличаться)
Burden: 33 Ом на GND; сигнал снимается ЧЕРЕЗ AC-связь:
  C_C1/C_C2 = 1 мкФ C0G/PPS (X7R запрещён — пьезоэффект), после них R_BIAS 470 кОм на 1.5 В каждый вход
  (без AC-связи: на GND — клиппинг −0.42 В; на bias — 45 мА DC через вторичку → насыщение сердечника)
Усилитель: AD8237 (zero-drift instrumentation amp, НЕ изолированный), Gain = 3
  10 А → 0.37 В RMS diff; 24 А → 1.26 В пик — симметрично вокруг 1.5 В без клиппинга
Опора: REF3033 (3.0 В fixed) → делитель 10к/10к → буфер OPA314 (RRIO) → 1.5 В mid-rail
ADC: GPIO1 = ADC1_CH0, attenuation 12 dB, входной R 1 кОм + BAV99 clamp на 0/3.3 В
```

### 13.2 Батарея / NTC
```
BAT: делитель 47 кОм (верхнее плечо) / 10 кОм (нижнее), ratio 5.7, node 100 нФ
  14.4 В → 2.53 В · 12.0 В → 2.10 В · 10.5 В → 1.84 В (весь диапазон в ADC 0–3.1 В)
  Thevenin 8.2 кОм — приемлемо для ESP32-S3 ADC @12 dB
  BATT_DIVIDER в power_mgmt.c = 5.7f (синхронизировать с кодом!)
NTC (батарея): 10 кОм @25 °C, B=3950, делитель 10 кОм к 3.3 В → GPIO8 = ADC1_CH6 (§14)
```

## 14. Pin-map и интерфейсы (синхронизировано с `hal_board.h`, custom-v1)

Соответствие прошивке: **CT = GPIO1 (ADC1_CH0), BAT = GPIO2 (ADC1_CH1), NTC = GPIO8 (ADC1_CH6)** — ровно как в текущем `components/hal_board/include/hal_board.h` (конфликтных назначений нет, ADC-карта зафиксирована без оговорок). GPIO2 остаётся strapping-пином (boot mode): использовать **только как analog input**, external pull-up на узле делителя не требуется (вход ADC high-Z; узел 47к/10к сам держит < 1 В при powered-boot без АКБ — boot не зависает, но строчку «не дёргать GPIO2 внешними сигналами» внести в schematic notes).

| Функция | GPIO | Примечание |
|---------|------|------------|
| Triac drive (MOC3023 LED) | **GPIO10** | R_LED 220 Ом, pull-down 100 кОм на узле; домен LOGIC (§8) |
| Relay K1 OPEN | **GPIO11** | → mutual-lock 74LVC2G08 → 2N7002 → катушка + SS54 |
| Relay K2 CLOSE | **GPIO12** | аналогично K1 |
| Relay K3 SHUNT | **GPIO13** | отдельный 2N7002, включение только в Phase B (zero-current окно) |
| ZC / mains-loss (H11AA1) | **GPIO14** | open-collector, pull-up 10 кОм, NEGEDGE ISR |
| Encoder A / B | **GPIO15 / GPIO16** | OC + pull-up 4.7 кОм, RC 1 кОм/10 нФ, Schmitt 74LVC2G14 |
| Limit CLOSED / OPEN | **GPIO17 / GPIO18** | NC-контакты; та же формирование; wire-break detect |
| Probe obstacle | **GPIO21** | опционально; PRTR5V0U2X |
| BTN OPEN / STOP / CLOSE | **GPIO4 / GPIO5 / GPIO6** | RTC-capable (ext1 wake), pull-up, long ≥ 1.5 с |
| Buzzer (LEDC) | **GPIO7** | 2N7002 low-side, passive buzzer |
| Status LED | **GPIO38** | plain LED (WS2812 — будущий вариант) |
| USB-C D− / D+ | **GPIO19 / GPIO20** | native USB; ESD USBLC6-2SC6 |
| UART0 TX / RX | **GPIO43 / GPIO44** | console + J_LINK camera module |
| I²C SDA / SCL | **GPIO40 / GPIO39** | DS3231M + 24LC256; pull-up 4.7 кОм |
| ADC1_CH0 | **GPIO1** | CT burden через AC-связь (§13.1) |
| ADC1_CH1 | **GPIO2** | BAT divider 47к/10к ratio 5.7 (§13.2) |
| ADC1_CH6 | **GPIO8** | NTC 10k B3950 (§13.2) |
| Spare | **GPIO3** | test point; strapping (JTAG source) — не тянуть наружу при boot |

Запрещены наружу: GPIO26–32 (flash), GPIO33–37 (octal PSRAM), GPIO45/46 (strapping/VDD_SPI). Камера на основной плате отсутствует (§5) — линии CAM_* в hal_board.h для custom-v1 профиля заведены в −1.

## 15. Защита линий

Для всех внешних сигнальных линий — **PRTR5V0U2X** (rail-clamp массив на 3.3 В/GND, VC ≈ 4 В < abs max ESP32 3.6 В + series R):

| Разъём | Защита |
|--------|--------|
| J_ENC (энкодер, кабель ≤ 15 м) | PRTR5V0U2X на A/B + series 1 кОм |
| J_LIMIT (концевики, ≤ 15 м) | PRTR5V0U2X ×2 канала + series 1 кОм |
| J_PROBE (датчик препятствия) | PRTR5V0U2X + series 1 кОм |
| J_CT (split-core, ≤ 2 м) | SMAJ5.0A на вторичку (AC-сторона CT, до burden) + BAV99 на ADC |
| USB-C | USBLC6-2SC6 |
| J_LINK (camera) | PRTR5V0U2X на UART/I²C |

**Использование SMAJ5.0A на GPIO запрещено** (VC 9.2 В разрушает GPIO раньше, чем TVS ограничит).

## 17. Стратегия тестирования (bring-up checklist)

1. **Hi-pot перед первой подачей:** первичка↔вторичка 3 кВ AC/60 с (через выбранные reinforced-реле — сверить паспорт), barrier slot inspection.
2. HLK-10M12 под нагрузкой 0.5 А: 12 В ±5 %, пульсации < 200 мВ.
3. TPS563201: 3.3 В, ripple, КПД; тепловизор.
4. GPIO sweep: все выходы через тест-пин-лист; **§8.4a reset-state test: осциллограф на Q1/Q2 gate при hold-in-reset — ожидание 0 В на обоих** (fail-off).
5. ZC: GPIO14 фронт каждые 10±0.5 мс; **loss-of-mains detection ≤ 60 мс** (бюджет 55 мс, §9).
6. Triac phase-angle: угол 30°…150°, форма тока, отсутствие ложных открытий; BTA16 ΔT на 3 А/30 мин ≤ 40 К.
7. CT chain:инжект  1/5/10/24 А → линейность AD8237, проверка отсутствия DC через вторичку (мкл-амперметр), fc AC-связи.
8. BAT divider: 10.5/12.0/14.4 В → ADC counts, пересчёт BATT_DIVIDER=5.7.
9. Encoder/limits: 15 м кабель, EFT burst ±1 кВ — ложных фронтов нет; wire-break logic test.
10. UPS switchover: сеть off → время падения шины < 10 мс (C bulk), ток АКБ; charge path отсутствует (D5-a) — verify.
11. Wi-Fi: RSSI с внешней антенной, TX peak current ≤ 500 мА от buck.
12. EMC pre-scan: CISPR 32 B conducted, RE 30 М–1 ГГц.
